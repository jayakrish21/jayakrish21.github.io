RAG Knowledge Assistant

What: A context-aware assistant that answers questions using internal documents with citations.

Why: Reduce search-to-insight time, improve trust with grounded answers, and unify knowledge silos.

How it’s used: Policy/FAQ lookup, internal support, research synthesis; foundation for enterprise knowledge hub.

Stack: FastAPI · LangChain · Chroma/FAISS · HF/OpenAI embeddings · Azure/OpenAI/Ollama LLMs · PyPDF/Unstructured.

AI Concepts: RAG (chunk → embed → retrieve) · vector similarity · prompt augmentation · grounded generation.

Learnings: Chunk/overlap tuning, embedding choice, ACL-aware retrieval, RAGAS evaluation, cost-aware provider routing.

AI Text Summarization Service

What: A microservice that converts long text into concise executive summaries with length control.

Why: Standardize summaries for leadership and client communications; speed up content review.

How it’s used: Summarize reports, transcripts, or policies; embeddable API; Streamlit/Vue UI for quick use.

Stack: FastAPI · Streamlit/Vue · dotenv · Azure/OpenAI/Ollama LLMs.

AI Concepts: Prompt design for concise output, temperature/tokens control, output formatting.

Learnings: Provider abstraction, deterministic prompts, token budgeting, UX for AI outputs.

AI Agent Orchestrator (Phase 1)

What: A pluggable layer that routes tasks to specialized agents (summarize, classify, keywords).

Why: Evolve from single-task LLMs to composable workflows; enable reuse across products.

How it’s used: One API for multiple AI capabilities; path to multi-step decisioning and tool use.

Stack: FastAPI · LangChain (agents/tools) · Vue UI · Azure/OpenAI/Ollama provider routing.

AI Concepts: Agentic patterns (plan → act → reflect), tool/function calling, orchestration.

Learnings: Interface contracts for agents, policy-based routing, observability of agent steps.
